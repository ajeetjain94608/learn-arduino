Contact

Learn Arduino is open source, so every message goes to one public place: its GitHub page. Anyone can see what was asked and what was fixed.

Write to us on GitHub

You need a free GitHub account to write. You can also read what others have asked first.

What to write about

  • Something does not work — say which page or project, what you did, what you expected, and what happened (a screenshot helps). Say which browser or phone you use.
  • A mistake in a tutorial — the tutorial's address and the sentence that is wrong.
  • An idea — a part, a project or a tutorial you would like to see.
  • Privacy, ads or the site's rules — see Privacy and Terms first; ask if anything is unclear.

Please do not post

Messages on GitHub are public: do not include passwords, your address, your phone number or anything else private.
