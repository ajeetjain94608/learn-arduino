# The UNO board layout data

`uno-layout.json` is extracted from Arduino's official UNO Rev3 design files (`UNO-TH_Rev3e.brd`, from
https://docs.arduino.cc/hardware/uno-rev3/), which are licensed under the
[Creative Commons Attribution-ShareAlike 4.0 licence](../../../../LICENSES/CC-BY-SA-4.0.txt).
This data is shared under the same licence, CC BY-SA 4.0.

Credit: "Board layout based on Arduino UNO Rev3 design files (CC BY-SA 4.0)".

The code in this folder that reads the data and builds the 3D board is under the project's licence (GNU AGPL 3.0, `LICENSE`).
